# Real Estate Big Data Analytics Pipeline

## 📌 Project Overview

This project is an end-to-end Big Data project for analyzing real estate transaction data using Python, PostgreSQL, Hadoop, MapReduce, HBase, and Hive.

The project demonstrates how large-scale data can be explored, stored, processed, and analyzed using different data engineering and Big Data technologies.

## 🎯 Project Objectives

* Analyze large-scale real estate transaction data.
* Perform data exploration and statistical analysis using Python.
* Store and query data using PostgreSQL.
* Upload and process large datasets using Hadoop HDFS.
* Implement MapReduce operations such as Mean, Max, Min, Count, and Sum.
* Store and retrieve data using HBase with multiple Column Families.
* Query and analyze Big Data using Apache Hive.
* Practice Git and GitHub for project version control and documentation.

## 📊 Dataset

**Domain:** Real Estate

**Dataset:** Dubai Real Estate Transactions

**Format:** CSV

**Size:** Approximately 607 MB

The dataset contains real estate transaction information such as transaction identifiers, transaction types, property information, dates, locations, and financial information.

> The original dataset file is not uploaded to GitHub because of its large size.

## 📚 Project Tasks

### Task 1 — Python Data Analysis

* Load and inspect the dataset.
* Explore the data.
* Perform statistical analysis.
* Calculate Mean, Median, Min, Max, Sum, and Count.
* Perform filtering and grouping.
* Analyze real estate transactions.
* Create visualizations.

### Task 2 — Python + PostgreSQL

* Create a PostgreSQL database.
* Create tables for real estate transactions.
* Load data into PostgreSQL.
* Connect Python with PostgreSQL.
* Query and analyze the stored data.

### Task 3 — Hadoop + MapReduce

* Upload a dataset larger than 128 MB to HDFS.
* Verify HDFS storage.
* Process the dataset using MapReduce.
* Calculate Mean, Max, Min, Count, and Sum.

### Task 4 — HBase

* Create an HBase table.
* Use multiple Column Families.
* Insert records.
* Retrieve records.
* Scan the table.
* Update and delete records.
* Perform advanced HBase operations.

### Task 5 — Hive

* Configure and run Hive.
* Create Hive tables.
* Load data.
* Execute HiveQL queries.
* Perform aggregations and grouping.
* Analyze the real estate data.
